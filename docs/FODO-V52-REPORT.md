# FODO v52 report: FODO Studio on the website (`/studio/`)

The owner asked to bring the FODO Studio desktop app (social media, studio, marketing) onto fodo.co.in so anyone can sign in
with their FODO account and use it, with two conditions: all processing power (clipping, editing, rendering) comes from the
user's own computer, never from FODO's servers, and the Studio must look exactly like the app.

## What the person gets
- **`/studio/`**: the FODO Studio app layout (same sidebar, cards, fonts, icons, Light / Dark / Auto) on desktop and phone
  (phone: top bar + slide-in menu). Workspace ▸ Social Studio opens it. Logged out: a login card that goes to the FODO login.
- **Home:** 7-day scheduled / posted, drafts to approve, inbox leads, followers, failures; "Up next" list.
- **Calendar:** month view per project, drag a scheduled post to another day (time stays), ideas shown on their day.
- **Publish:** media library (chunked upload, 4 MB parts), composer (accounts, title, caption, AI caption via Workers AI,
  next free slot / pick a time / post now / draft), filters, approve, post now, cancel, delete.
- **Inbox:** comments from connected accounts, tags (lead / question / complaint), AI reply suggestion, saved replies, reply
  (needs "Allow replies" permission on connect).
- **Clients:** projects (one per brand / client, colour, time zone, posting slots), connect Instagram / Facebook (Meta) and
  YouTube (Google), manual accounts, client approval links.
- **Content planner:** idea board with drag between stages, AI ideas.
- **Analytics & reports:** views / likes / comments, top videos, best-time heatmap, printable report and CSV (formula-safe).
- **Link in bio:** editor with live phone preview, public page `/l/<slug>` with click counter (`/l/<slug>/go/<key>`).
- **AI Clipping / Editor / Caption & Font Studio:** detect the FODO Studio app on this computer (`127.0.0.1:8777`) and open it;
  device keys let the app send finished clips to the cloud library (`/api/social/agent/*`). No clipping runs on FODO servers.

## How it works
- `functions/_lib/sstudio.js`: tables `ss_projects`, `ss_accounts`, `ss_follow`, `ss_media`, `ss_posts`, `ss_ideas`,
  `ss_comments`, `ss_replies`, `ss_links`, `ss_bio`, `ss_devices` (SETUPS module `sstudio`, `SCHEMA_VERSION` 52.0).
  Tokens sealed with `GSC_ENC_KEY`. Media in R2 `MEDIA` when bound (500 MB per file, 10 GB per user), else KV (100 MB / 400 MB).
  Platforms fetch media through short-lived HMAC-signed URLs with Range support.
- Publishing is a resumable state machine (Instagram Reels by `video_url`, Facebook `/videos` by `file_url`, YouTube resumable
  upload) advanced by `sstudio.tick`, called from the hourly `/api/monitor/jobs`.
- `functions/api/social/[[path]].js`: session routes for every feature; writes need same-origin + JSON; raw part uploads need
  `x-fodo-upload: 1`. Public: signed media, approval page data / decision, agent routes (Bearer device key, stored hashed).
- Front end: `studio/index.html` (generated by `scripts/build_pages.py`, no inline script), `js/fodo-studio-theme.js`,
  `js/fodo-studio.js` (shell, provides `window.FODO_WS`, maps the shared view classes onto the app's components),
  `js/fodo-studio-ui2.js` and `css/fodo-studio.css` (copied from the app), `js/ws-social.js` (all views).
- `/studio/*` headers: noindex, no-store, strict app CSP. robots.txt disallows `/studio/`. connect-src allows
  `127.0.0.1:8777` / `localhost:8777` (app detection only).

## Owner set-up before public use
1. Meta app: add redirect URI `https://www.fodo.co.in/api/social/oauth/meta`; App Review for `instagram_content_publish`,
   `pages_manage_posts`, comments permissions before people outside the app's testers can connect.
2. Google OAuth client: add redirect URI `https://www.fodo.co.in/api/social/oauth/google`; YouTube upload scope needs Google
   verification for public users.
3. Optional: R2 bucket `fodo-media` bound as `MEDIA` for uploads above 100 MB.
