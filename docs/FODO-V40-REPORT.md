# FODO v40: Business OS (Workspace, Brand Kit, Content & Ads, FODO Pros marketplace)

Brief: "FODO V39/V40 One-Pass Master Implementation Prompt". This report says exactly what was built, what works, and what is still not done or needs an outside provider.

## 1. What was built

All of it runs on the existing Cloudflare Pages + Functions + D1 stack. There is no new framework.

| Area | Files |
|---|---|
| Server library | `functions/_lib/biz.js` |
| API | `functions/api/biz/[[path]].js`, i.e. `/api/biz/*` |
| Workspace page | `/workspace/`: generated by `build_pages.py`, `js/workspace.js`, `css/workspace.css`. Private: noindex, robots Disallow, not in the sitemap, `no-store`. |
| Payments | Existing checkout. New kind `milestone` in `functions/api/account/[[path]].js`; the milestone is funded in `accounts.finishPaid`. |
| X-Ray → actions | `js/xray.js` `fixLinks()` on the Top 5 Actions; same rules as `biz.actionsFor()` |
| Brain | `mk_overview` (level 0), `mk_pending_pros` (level 0), `mk_moderate_pro` (level 1, confirm) |
| Links into the workspace | Growth Lab hero, account page (Builder panel), builder home nav |

## 2. Feature by feature

### Workspace
- Navigation follows each person's roles: Overview, Website Builder, Business X-Ray, Growth Lab, Content & Ads, Hire FODO Pros, Projects, Brand Kit, My Pro profile, Billing, Notifications, Marketplace admin.
- Roles are decided on the server:
  - **owner**: owner emails;
  - **admin**: `acct_admins` admin;
  - **moderator / finance / viewer**: `biz_staff`, set by owners only;
  - **pro**: has a profile;
  - **client**: everyone.
- Phone: slide-in menu, sticky top bar with notifications. Checked at 390 px with no sideways scroll.

### Overview (Business dashboard)
- Cards with real numbers:
  - Digital Growth Health (last X-Ray score);
  - websites (total / live);
  - leads in the last 30 days (form submissions);
  - content (due this week / published);
  - campaigns (planned / ready; live = "needs a connected ad account");
  - active projects;
  - money spent on projects;
  - upcoming bookings;
  - alerts.
- **Next Best Action** comes only from the account's data:
  - review submitted work;
  - fund a milestone;
  - review a proposal;
  - reply to a request;
  - run an X-Ray;
  - create or publish the website;
  - fix a low X-Ray score;
  - set up the Brand Kit;
  - plan content.

### Brand Kit
- Name, tagline, logo (https), 5 colours (hex only), heading and body fonts, radius, tone, audience, dos and don'ts.
- **Extract from website** reads the real theme of one of your websites.
- **Apply to website** saves a normal new version of the site, which can be undone from History.
- Content briefs use the Brand Kit's tone and colours.

### Content & Ads
- Content items with 8 statuses: Idea, Brief, Assigned, In production, Review, Approved, Scheduled, Published.
- Three views: List, Board and Month calendar.
- **Brief builder**: format, count, platform, objective, audience, offer, CTA, tone, deadline, budget and references go in. Out come deliverables, the recommended format and the professional roles that fit. It is rules-based, so it works without AI.
- "Hire a FODO Pro for this" opens the marketplace filtered to the right role and links the project back to the content item.
- **Ad campaign planner**:
  - Fields: Meta, Google, LinkedIn, YouTube or TikTok; objective, budget, days, daily budget, audience, KPI, landing page, creatives.
  - Status is only Draft or Ready. **"Live" is never set**: publishing needs that ad account connected.

### FODO Pros
- **Roles:** 42 professional titles in 8 categories. They are never called "workers".
- **Signup (5 sections):**
  1. Identity
  2. Skills & experience
  3. Location & languages (remote, on-site, radius)
  4. Availability & rates (working days, blackout dates, minimum notice, day rate)
  5. Payments & terms
- Packages (name, price, turnaround, revisions, deliverables, usage rights) and portfolio (https links only).
- **Completeness:** a profile can't be submitted until it is complete, and the exact missing items are listed.
- **Profile states:** Draft → Pending → Approved / Published / Rejected / Suspended / Archived. Changing an approved profile sends it back to Pending review.
- **Privacy:** profiles are visible only to signed-in clients inside the workspace. There is no public page and no public SEO directory.
- **Matching, deterministic** (works without AI):
  - "I need a cinematographer in Delhi for a one-day restaurant shoot, budget ₹20,000" is understood as role + city + budget + days + industry.
  - Ranking uses role, skills, city / remote, budget, experience, verification, real rating and real completed count, and shows the reasons for each match.
- **Rating and "completed on FODO"** come only from real reviews and completed projects. A new profile shows "No reviews yet".
- Shortlist with notes.

### Projects
- **State machine** (server-enforced, atomic transitions): requested → proposed → accepted → in_progress → delivered → completed. Cancelled and disputed are also possible.
- **Proposal:** the professional sends milestones. The client accepts. A booking day is reserved with a unique index, so two clients can never book the same professional on the same day; a new request for a booked day is refused too.
- **Paying a milestone:**
  - The client pays through the existing Razorpay / Cashfree checkout.
  - The amount comes from the database.
  - Only the project's client can pay, and only once.
  - The milestone is funded only after the gateway confirms payment.
- **Work:** the professional submits work. The client approves or requests changes.
- **Approval** creates a payout row with the commission (default 10%, owner-set, max 40%). When every milestone is approved, the project is completed and the professional's completed count goes up.
- **Review:** only by the client, only after completion, and only once.
- **Messages:** inside the project, between client and professional.
- **Cancel:** only while no money is in the project; otherwise a dispute is opened.
- **Notifications:** on every step, for the other side.

### Marketplace admin (moderator / finance / admin / owner)
- Overview numbers from the data.
- Review queue: approve, publish, reject, suspend, archive or restore, with a note. The professional gets a notification, plus an email on approve or reject.
- **Payouts:** finance marks a payout paid with the bank or UPI reference, once only.
- **Disputes:** resolve as continue, completed or cancelled (cancelled releases the booking).
- **Settings (owner only):** marketplace roles and commission.

### Billing
- One place showing the Growth Lab plan, the Website Builder level, receipts (account ledger) and project payments.
- Everything uses the same payment system and the same order table; nothing is duplicated.

## v40.1: FODO Pros portal (invite-only)

**The page:** `/fodo-pros/` is one page that holds both the professional's profile and their dashboard.
- It is **not linked anywhere**: no menu, no footer, no other page, not in the sitemap.
- It is hidden from search and other sites: `noindex, nofollow`, robots Disallow, and `no-referrer` (the invite token never leaks to another site).

**Invite-only:**
- Creating a profile needs an invite link `/fodo-pros/?i=<24-char token>`.
- Owners, admins and moderators create links in **Workspace → Marketplace admin → Invite links**. Each link has a note, a number of uses (default 1) and a validity period (default 14 days). Links can be copied, shared on WhatsApp, or revoked.
- Use is atomic: a 1-use link works once.
- A wrong, used, expired or revoked link shows "FODO Pros is invite-only".
- `GET /api/biz/invite?i=` only answers valid / not valid.
- Existing professionals just log in at `/fodo-pros/`.

**Clients:** the client workspace no longer shows any "Pro profile" link. Only accounts that already have a profile get the Pro area.

**Professional dashboard (real data only):**
- **Dashboard:** what to do next (send proposal, deliver a paid milestone, complete profile, submit), new requests, active and completed projects, earnings after commission, pending payout, rating, reply rate, upcoming bookings, disputes.
- **My profile:** signup, packages, portfolio, submit for approval.
- **Requests & projects:** proposals, delivery, chat.
- **Calendar:** month view with bookings, blocked dates and days off. Tapping a date blocks or unblocks it. A booked day can't be blocked, clients can't book blocked days, and blocking does not send the profile back to review.
- **Earnings & payouts:** commission and transfer references.
- **Reviews.**
- **Notifications.**

The approval email links to `/fodo-pros/`.

**Tests:** `v40.test.mjs` now has 99 checks: invite-only signup, one-use / revoked / fake links, client nav, the pro dashboard, blackout dates, and the unlisted-page checks.
- **Full suite after v40.1:** 57 suites, **3,540 checks, 0 failing**.

## v40.2: builder loading fix, Workspace link, Leads / CRM, global search, receipts

**Builder loading:**
- Before the builder started, the page showed its plain SEO text ("FODO Website Builder: build a business website…").
- It now shows a **branded loader** (FODO + spinner + "Loading FODO Website Builder…"). The SEO copy stays in the HTML for search engines and appears only if JavaScript is off.
- All ~25 builder modules are **preloaded in parallel** (`<link rel="modulepreload">` with the same versioned URLs as the import map), so the builder opens directly instead of loading files one after another. Local test: ready in about 1.1–1.8 s.
- The load guard no longer shows an error on a slow connection. It says "Still loading, slow connection…" and waits up to about 25 s. A real failure (missing file, script error) still shows the reason and a Reload button.

**Workspace link:** signed-in people get a **Workspace** button next to their account in the header (wide screens) and in the mobile menu.

**Leads / CRM** (`/workspace/#leads`):
- Every form enquiry from your FODO websites, with name, email, phone and message picked out.
- Tap to call, WhatsApp, or email.
- Pipeline: New → Contacted → Qualified → Won / Lost, with notes, filters and search.
- Strictly your own websites only.

**Global search:** Ctrl+K (or ⌕) in the Workspace searches your websites, projects, content, campaigns and approved FODO Pros, plus "Find a <role>" and quick jumps to every page.

**Receipts:**
- Workspace → Billing lists every paid order with a **Receipt (PDF)** link: a printable page, "Print / Save as PDF".
- It is titled "Payment receipt". It becomes a "Tax invoice" with your GSTIN only when the Cloudflare variable `FODO_GSTIN` is set; FODO never invents a GST number.
- Only the payer can open it.

**Small fix:** changing page closes any open dialog in the Workspace.

**Tests:** `v40.test.mjs` now has 115 checks (leads, search isolation, receipts, loader, header link).
- **Full suite after v40.2:** 57 suites, **3,556 checks, 0 failing**.
