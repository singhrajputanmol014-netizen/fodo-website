# FODO — Fear Of Digitally Out ? — Website

Lean static site (plain HTML/CSS/vanilla JS). **16 primary routes + 404.** No build step; works as a local folder preview and on Cloudflare Pages.

## Routes
| Route | Contains |
|---|---|
| `/` | Home (hero, growth signal, system preview, work/insights teasers, **Growth Lab** section at `/#growth-lab`) |
| `/about/` | About + **Founder** (`#founder`, text only) + **Growth System** (`#growth-system`, interactive 6 stages) |
| `/services/` | Hub with filters + all **20 services** as detail states, e.g. `/services/#meta-ads` |
| `/industries/` | Hub + 7 industry detail states, e.g. `/industries/#saas` |
| `/work/` | 6 concept case studies (filters + detail states) |
| `/insights/` | 8 articles (search + category filter + detail states) |
| `/resources/` | 5 interactive checklists (progress, copy, print, reset) |
| `/growth-score/` | 10-input self-assessment, rules-based score |
| `/roi-calculator/` | Live INR scenario calculator |
| `/fodo-challenge/` | 4-round game + reward state (discounts OFF) |
| `/marketing-quiz/` | 10-question quiz |
| `/contact/` | 5-step form. Modes: `?mode=audit` (Free Growth Audit), `?mode=call` (Book a call), `?mode=contact` |
| `/reviews/` | Client reviews — `reviewsMode` in config: `preview` (demo data + banner) or `live` (only verified reviews from `js/reviews.js`) |
| `/faq/` | Searchable FAQ + Pricing approach (`#pricing`) |
| `/legal/` | Privacy (`#privacy`), Cookies (`#cookies`), Terms (`#terms`), Disclaimer (`#disclaimer`) |
| `/thank-you/` | Confirmation states (`?state=sent` or `?state=whatsapp`) |

Old 50-page URLs (`/free-growth-audit/`, `/book-a-call/`, `/founder/`, `/pricing/`, `/privacy/` …) are redirected in `_redirects`.

## Edit content
* **Business details & switches:** `js/config.js` (email, phone, WhatsApp, address, LinkedIn, `formEndpoint`, `bookingUrl`, `discountsEnabled`).
* **All copy/data:** `js/data.js` — services, industries, case studies, articles, FAQs, stages, checklists, quiz, game rounds.
* **Page shells:** generated by `scripts/build_pages.py` → run `python3 scripts/build_pages.py` after editing it (it also rewrites `sitemap.xml`, `robots.txt`, `_redirects`).
* **Founder statement** is marked `DRAFT TO APPROVE` on `/about/`. FAQ answers with `[CONFIRM WITH FODO BEFORE PUBLICATION]` need a decision.
* **Real work / testimonials:** edit `FODO_DATA.cases` and remove the CONCEPT labels only for approved, verified cases. Home testimonials block says `CLIENT STORIES COMING SOON` until real quotes exist.

## Preview locally
Double-click `index.html`, or run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

## Deploy (Cloudflare Pages)
Upload this folder (or connect a Git repo). Build command: none. Output directory: `/`. `_redirects` and `404.html` are picked up automatically. Add custom domain `www.fodo.co.in`; redirect `fodo.co.in` → `www` in Cloudflare Rules so there is one canonical host.

## Forms (important)
`formEndpoint` is blank → submitting opens **WhatsApp** with the answers pre-filled (visitor presses Send) and offers **Copy my details**. Nothing is emailed. To receive submissions by email: create a Formspree form (or Google Apps Script / Netlify Forms), paste its URL into `formEndpoint`, submit a test, and confirm it arrives. The site POSTs JSON. Never put API keys in `config.js`.
Booking: paste a Calendly/Cal.com URL into `bookingUrl` to show a self-booking link on `/contact/?mode=call`.

## Rewards
`discountsEnabled:false` (default): scores under 40 get the free consultation offer; higher scores get a completion state + playbook link. Set to `true` only after terms are final — tiers in `discountTiers`, validity in `rewardValidityDays`. Browser codes are never proof; FODO verifies manually.

## Audit
`python3 scripts/audit.py` — checks routes, dead links, local targets, titles/descriptions/H1, button types, sitemap. See `QA-report.md`.

## Launch checklist
Test all 16 routes on phone + desktop · submit a test form (WhatsApp and, if configured, endpoint) · tap WhatsApp/Instagram/email/LinkedIn links · review legal drafts with a lawyer · decide FAQ `[CONFIRM…]` items · approve founder statement · decide on discounts.
