# FODO: fodo.co.in

FODO ("Fear Of Digitally Out ?") is a New Delhi digital growth agency. This repository is its whole platform on
Cloudflare Pages + Functions + D1 + KV + Workers AI:

- **Public site:** 102 routes generated by `scripts/build_pages.py`.
- **Growth Lab:** Business X-Ray, Pro tools, Competitor Finder, plans and payments.
- **Website Builder:** AI website creation, a visual editor, store, blog and publishing, plus the separate `fodo-sites` project in `sites/` that serves client websites.
- **Owner Brain:** a private AI command centre with voice.
- **Admin:** the FODO team's dashboard.

## Everyday commands

```
python3 scripts/build_pages.py   # regenerate pages, sitemap, robots.txt, search index
npm run setup                    # once: test tooling (kept in tests/, never deployed)
npm test                         # all suites
npm run audit                    # SEO + secret scan + performance
```

## Ground rules

- Secrets live only in Cloudflare secrets.
- No fake data, reviews, metrics or deployments.
- The owner emails get everything free; only owners change admin settings.
- Client websites can never reach FODO's admin, Brain, database or other clients.
