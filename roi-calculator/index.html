Current conversions = visitors × conversion rate. Current value = conversions × value per conversion. Projected conversion rate = current rate × (1 + assumed lift), capped at 100%. Projected conversions and value are recomputed the same way. Difference = projected value − current value. ROAS = value ÷ spend, shown only when spend > 0. Inputs are clamped to sensible ranges; negatives and non-numbers are ignored. No FODO pricing is included.
